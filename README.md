# Sweet Delights Bakery

A "Pay What You Want" bakery website hosted on GitHub Pages.

## Features
- Pay what you want for baked goods.
- Support us with tips.
- Simple and free to set up!

## How to Use
1. Clone this repository.
2. Replace the PayPal button IDs with your own.
3. Customize the menu and styling.
4. Push changes to GitHub to update your website.
